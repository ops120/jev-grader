# 题库模板使用说明

> **第一次做题库？** 先看 [GUIDE.md](GUIDE.md) 的手把手流程（准备材料 → 逐题型示例 →
> 上传排错 → 自检清单）。本文是字段速查，两篇配合用。

本仓库**不做试卷提取**。改卷工作台只认一种输入：按本模板填写的题库 JSON。
本文档描述这份 JSON 的每个字段；同目录的 `bank_template.json` 是一份可以直接
上传跑通的完整示例（原创演示题）。

三种上传方式，任选其一：

1. **工作台**：顶栏「上传题库」选择 JSON 文件——结构验收通过即入列，不通过会逐条给出原因；
2. **放文件**：把题库 JSON 放进 `data/banks/`（文件名去扩展名即试卷 id），刷新页面即可；
3. **命令行**（先组装请求体再发送，避免大 JSON 在 shell 里被引号截断）：

   ```bash
   python - <<'PY'
   import json
   bank = json.load(open("my_exam.json", encoding="utf-8"))
   json.dump({"name": "my_exam.json", "bank": bank},
             open("_upload_payload.json", "w", encoding="utf-8"), ensure_ascii=False)
   PY
   curl -X POST http://127.0.0.1:8848/api/upload \
        -H "Content-Type: application/json" --data-binary @_upload_payload.json
   ```

> 验收器只检查**结构与一致性**（字段、引用、编号、spec 认领）。题面内容是否与
> 原件一致，机器在没有原件物证的情况下无法判断——上传题库的「题库核验」会一直
> 显示未核验，这是如实的，不是缺陷。**题面错一行，改卷就错一题**，内容正确性由
> 制作者负责。

## 顶层结构

```jsonc
{
  "meta":     { ... },   // 必填：这份题库是什么、用哪套判定 spec
  "sections": [ ... ],   // 可选：小节清单（名称、分值）
  "passages": [ ... ],   // 可选：共享阅读材料（完形填空/阅读理解的篇章）
  "items":    [ ... ]    // 必填：题目数组，至少一道
}
```

## meta

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 试卷标题，显示在顶栏与答案汇总 |
| `subject` | ✅ | 科目名，显示在试卷切换器 |
| `specs` | ✅ | 判定 spec 名数组，见下表 |
| `has_latex` |  | 题干/选项含 `$…$` 行内公式时设 `true`（走 KaTeX 渲染） |
| `id_prefix` |  | 轨迹文件名前缀（单字母，默认 `Q`）。从旧版题库迁移时写上原前缀（如 `M`、`X`），既有轨迹才能继续被认领 |
| `paper_note` |  | 题库说明（原件缺陷、制作备注），显示在体检报告 |
| `known_text_layer_defects` |  | 已核实的原件缺陷清单（字符串数组），逐条显示在体检报告 |

**specs 怎么选**（可选值只有 `src/judge/specs/` 下这四个）：

| specs | 适用于 | 条目 kind |
|---|---|---|
| `["english"]` | 英语类卷（默认） | `mcq`／`cloze`／`seven`；`kind` 可省略（默认 mcq） |
| `["xingce"]` | 行测等中文单选卷 | 材料题给 `material` 字段；小节名含「选词填空」自动按 `cloze` 处理 |
| `["math", "math_multi"]` | 数学卷 | **每个条目必须写 `kind`**：单选 `math_single`、多选 `math_multi` |

数学卷的 spec 都声明了只认领自己的 kind，没有兜底 spec——漏写 kind 的条目会被
验收器逐条点名拒绝，而不是悄悄套错编排。

## sections（可选）

| 字段 | 说明 |
|---|---|
| `name` | 必填。条目通过自己的 `section` 字段关联到同名小节 |
| `part` | 可选。大题号（如「一」），与 name 一起构成唯一键 |
| `per` | 每题分值。计分时优先用条目自带的 `score`，缺了退回这里的 `per` |
| `full` | 小节总分（与 `per` 二选一） |
| `count` | 期望题数。与实际条目数不符会在体检报告里记一条告警（不拒绝上传） |

条目里出现 `sections` 没声明的小节名时自动补建并记告警——不会静默丢小节，
也不会静默丢条目。

## passages（可选）

| 字段 | 说明 |
|---|---|
| `id` | 必填，唯一。条目通过 `passage` 字段引用 |
| `label` | 可选，如 `"Passage One"` |
| `title` | 可选，篇章标题 |
| `paragraphs` | 段落数组（推荐），或用 `text` 给整段文本（空行分段） |

篇章会被自动切句编号（S1、S2…），判定过程的「证据定位」步引用这些句号。
完形填空的空位写作 `[3]____`（题号 + 下划线），系统据此登记题空并为该题
取带前后句的上下文。

## items（必填）

| 字段 | 必填 | 说明 |
|---|---|---|
| `no` | 建议 | 卷面题号（整数）。缺了按出现顺序自动编号并记说明 |
| `stem` | ✅ | 题干。含公式时写成行内 `$…$` |
| `options` | 见注 | `{"A": "…", "B": "…"}`，字母 A–G |
| `kind` | 建议 | 题型，见下表 |
| `section` / `part` |  | 所属小节 |
| `passage` |  | 引用的篇章 id |
| `material` |  | 行测类材料文本（单独一段题面前置材料） |
| `answer` |  | 标准答案（如 `"B"`、多选 `"ABC"`）。也可写字段名 `standard_answer` |
| `score` |  | 本题分值（计分用，缺了用小节 `per`） |
| `subs` / `appendices` / `table` / `crit_table` / `figures` |  | 可选透传字段：小问、附注、表格（`{"header": […], "rows": [[…]]}`）、临界值表、图形说明 |
| `answerable` + `notice` |  | 可显式声明该题**不可作答**并给原因（如「选项在原件中是图片」）。声明的条目原样展示原因、逐条登记在体检报告，不判缺损；未声明的条目按下面的规则自动判定 |

**注**：选择题/判断题必须给 `options`（判断题 `kind: "judge"` 只需 A/B 两项）。
写作、语法填空、数学填空与解答这类**天然没有选项**的题型可以不给——它们会被
如实标注为不可作答（本工作台只改选择/判断题），而不会被判成题面缺损。
数学卷里**不可作答**的条目不必写 `kind` 被任何 spec 认领（它们根本不会被求解）；
**可作答**的条目必须写对 `math_single` / `math_multi`。

## kind 一览

| kind | 含义 | 可作答 |
|---|---|---|
| `mcq` | 普通单选（默认） | ✅ |
| `cloze` | 完形填空/选词填空（选项 + 文中空位） | ✅ |
| `seven` | 七选五（选项 + 文中空位） | ✅ |
| `judge` | 判断题（A/B 两项） | ✅ |
| `math_single` / `math_multi` | 数学单选/多选 | ✅ |
| `listening` | 听力（无音频材料） | ❌ 原因：无录音原文 |
| `gapfill` | 语法填空（需生成词形） | ❌ |
| `writing` | 写作（需生成文本） | ❌ |
| `math_gapfill` / `math_solution` | 数学填空/解答 | ❌ |

未知 kind 不拒绝上传，但会记告警并按 spec 的默认措辞处理。

## 验收规则（error 即整卷拒绝）

- `meta` 缺 `title` / `subject` / `specs`，或 `specs` 指向不存在的 spec；
- 条目缺 `stem`、`no` 不是整数、`options` 键不是 A–G 单字母；
- 选项字母不连续（如只有 A、B、D，缺中间的 C）——选项不齐不猜，请补全或删掉；
- `passage` 引用了不存在的篇章 id；
- 数学卷（无兜底 spec）的条目 `kind` 没有被任何 spec 认领。

其余问题（重复题号、小节题数不符、答案含不存在的选项字母、篇章切不出句子等）
以**告警**随题库入库，全部显示在「答案汇总 → 题库体检」里。缺损题降级为
不可作答并保留原因，绝不静默删除。

同名上传会**替换**已存在的题库；从 `data/banks/` 删掉文件即下架
（已求解的轨迹在 `data/traces_<id>/`，不会自动删除）。
